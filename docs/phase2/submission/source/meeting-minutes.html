Week 1: Project kickoff

Week of 7 September 2026 · In person

Discussion

  • Course structure: four checkpoints (planning and design, front end, back end, integration and presentation), each with a demo.
  • Project choice: SolCacao, a bilingual chocolate storefront with a retail shop and a business-to-business custom-quote service, based on the project blueprint.
  • Splitting the work so each person owns one area end to end (front end and API): auth, shell/localization, catalog, B2B and support.
  • Collaboration model: one GitHub repository; protected main and development branches; every change through a pull request reviewed by another member.
  • Using AI coding assistants (four members on Claude Code, one on Codex). Ground rules: each member stays inside their own area, reviews every change before committing, shares no secrets or personal data with the tools, and uses only fictional demo data.

Decisions

  • Areas: Aman (auth and accounts), Varad (app shell, navigation, localization; team coordinator), Reethika (catalog, cart, checkout), Krish (homepage, wholesale, quote wizard), Daniel (contact, feedback, sampler, story and care pages).
  • Stack: React with Vite and Tailwind CSS; Node.js/Express with MongoDB (Mongoose); shared typed contracts between client and server.
  • Keep both schedules side by side: the blueprint's execution plan and the course checkpoints (D01).

Week 2: Data model and ERD

Week of 14 September 2026 · In person

Discussion

  • Each owner described the data their area needs: users, corporate partners and addresses (Aman); products, inventory, carts and orders (Reethika); quote requests and their PDF attachments (Krish); support enquiries and sampler requests (Daniel); localization dictionaries and public assets (Varad).
  • How authentication works across features and where a guest cart lives before sign-in.

Decisions

  • JWT access token held in memory with a one-hour expiry (D09).
  • Guest cart stored only in the browser (localStorage) and merged into the saved cart on sign-in (D10).
  • Business branding uploads are PDF only, maximum 5 MiB (D07), kept in private storage that is not publicly served (D12).
  • Aman coordinates global consistency of the ERD; each owner writes their own models.
