Aman Gulati: Authentication and accounts

  • PR #11 (+4,305 / −99, 42 files): sign-in and registration pages (retail and business accounts), a reusable sign-in dialog and route guards, and the account page with profile and address management.
  • Server foundation: JWT authentication middleware (requireAuth, optionalAuth, requireRole) used by the catalog and B2B routes; environment validation that refuses weak secrets; database bootstrap and health check; the account API.
  • Tests for validation, token handling (expired, tampered, wrong audience) and address ownership, plus a real-MongoDB persistence suite.
  • PR #19: recorded his Phase 1 status. He reports contributing to the ERD and schema design (users, corporate partners, addresses), the overview, the prototype and the Phase 1 demo.

His Phase 2 commit was recorded under his laptop's local email, so GitHub's contributor graph does not credit it to his account. Authorship is shown on PR #11 and in the commit itself. Later commits use his GitHub identity (#19).

Varad Tambe: Shell, localization and team coordination

  • Repository and Phase 1: created the repository and audited the starter structure against the course and blueprint requirements (PR #1). Aligned the database schema and ERD (PR #2).
  • PR #3 (+3,656 / −155): app shell, header and footer, mobile menu, English/Spanish routing and translation loading, page metadata, and shared UI components. Addressed Krish's seven review points before approval.
  • PRs #6–#8: test fixes for the homepage hand-over; a CC0 photography library, product images, favicon and social preview images (Krish requested changes on #8 before approving).
  • Integration (PR #12): connected Aman's authentication middleware and Daniel's quote notifications to the catalog and B2B routes, added a MongoDB service to CI so every member's persistence tests run, and wrote the cross-feature journey tests. Reviewed and merged by Daniel.
  • CI and releases: MongoDB 7.0 for CI (#13), a fix for a timing race in the quantity picker (#17), releases to main (#16, #20) and the main-to-development sync (#21).
  • Coordination: branch protection, weekly integration records, reviews of every member's Phase 2 PR, the submission checklist audit, the WCAG audit and its reflow fix, and the submission tag.

Reethika Gajulapati: Catalog, cart and checkout

  • PR #9 (+6,671 / −96, 44 files): catalog with URL-based filters (origin, cacao percentage, price, search), sorting and pagination; product detail page; cart drawer and guest cart; simulated checkout and order confirmation.
  • Product, cart and order API: cart revisions to prevent conflicting writes, a guest-cart merge on sign-in that applies only once, and checkout requests that can be safely retried, with totals recalculated on the server.
  • Adapter, cart-state, page and API tests, plus a real-MongoDB persistence suite.

Krish Ruparel: Homepage, wholesale and business quotes

  • PR #5 (+4,773 / −38, 39 files): homepage (hero and seasonal showcase), wholesale services page, and a four-step quote wizard with PDF upload that keeps the draft when switching language.
  • Quote API with private PDF storage: type, signature and size checks, cleanup of rejected uploads, duplicate-request handling, and owner-only access to receipts and files.
  • Wizard, page, adapter and API tests, plus a real-MongoDB persistence suite.
  • Reviewing: the team's most active reviewer, with 13 reviews on 11 PRs. He requested changes on the shell foundation (#3, seven points) and the image library (#8). He independently re-ran the full test suite, browser tests and a secrets scan before approving the first release to main (#16).

Daniel Yglesias: Support, sampler and content pages

  • PR #10 (+2,428 / −49, 39 files): contact and feedback forms, the six-piece sampler builder, and the Story and Care pages.
  • Enquiries API with validation, safe retries and HTML escaping, plus the email notification service, including the quote notification used by the B2B flow.
  • Follow-ups from his own testing: the sampler resets after a successful enquiry (#14), and catalog cards gained a quantity picker (#15).
  • Reviewing: reviewed and merged the integration PR (#12) after re-running the full test suite and all browser tests himself.
